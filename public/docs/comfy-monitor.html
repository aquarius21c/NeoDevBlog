comfy-monitor

ComfyUI 창을 띄우지 않고 돌릴 때, Claude Code 안에서 큐·VRAM·RAM·GPU 사용량을 상태줄과 그래프 패널로 보여 주는 모드(플러그인)입니다.

v0.4.1 테스트 20개 통과 plugin validate 통과 1~3단계 완료 GitHub 공개 · MIT 2026-10-27

WHY왜 만들었나요

Claude Code가 ComfyUI를 헤드리스로 실행해 영상을 만들게 하면, 지금 GPU가 얼마나 바쁜지, 큐에 작업이 몇 개 남았는지 볼 화면이 없습니다. 조사해 보니 ComfyUI 창 안에서 보는 도구(Crystools, Elegant Resource Monitor)는 있지만, Claude Code 안에서 ComfyUI 사용량을 그래프로 보여 주는 플러그인은 없었습니다. 그래서 직접 만들었습니다.

정리하면

ComfyUI 창을 띄워 두고 작업할 때는 Crystools로 충분하고, 창 없이(헤드리스로) 돌릴 때 이 모드가 필요합니다.

FEATURES기능

상태줄 한 줄 요약

실행·대기 수, VRAM, GPU 사용률을 늘 보이게 띄웁니다. ComfyUI가 응답하지 않으면 OFF로 바뀝니다.

10분 그래프 패널

GPU·VRAM·RAM·큐를 최근 10분(샘플 300개) 그래프로 보여 줍니다.

단계 진행률 · 알림

실행 중인 작업의 단계 n/m을 보여 주고, 완료·실패·중단 때 토스트를 띄웁니다. VRAM이 95% 이상으로 10초 이어지면 경고합니다.

안전한 종료

stop은 Claude가 띄운 ComfyUI만 끄고, 남은 작업이 있으면 먼저 물어봅니다.

INSTALL설치

명령을 입력하는 곳이 두 군데입니다

claude plugin … 명령은 PowerShell에, /reload-plugins와 /comfy-monitor … 같은 슬래시 명령은 Claude Code 입력창에 입력합니다.

GitHub에서 설치 (권장)

소스는 github.com/aquarius21c/comfy-monitor에 MIT 라이선스로 공개되어 있습니다. Claude Code 입력창에서:

/plugin install comfy-monitor --marketplace aquarius21c/comfy-monitor

셸에서는 claude plugin install comfy-monitor --marketplace aquarius21c/comfy-monitor입니다. 데스크톱 앱처럼 /plugin이 안 되는 곳에서는 입력창 옆 + → Plugins → Add marketplace에 aquarius21c/comfy-monitor를 넣고 Add plugin을 누릅니다. 설치 후 이미 열린 Claude Code에서는 /reload-plugins를 실행합니다.

설치 없이 한 번만 테스트

claude --plugin-dir <플러그인 폴더>

필요한 것

로컬 ComfyUI(기본 http://127.0.0.1:8188), GPU 사용률용 nvidia-smi, 단계 진행률용 websocket-client가 설치된 Python(pip install websocket-client)입니다. comfy나 python이 PATH에 없으면 설정의 comfyBin, pythonBin에 전체 경로를 넣어 주세요.

HOW동작 방식

세션 시작→2초 타이머→/system_stats · /queue · nvidia-smi→링버퍼 300개(10분)→상태줄 · 패널 · 토스트
항목읽는 곳
VRAM, RAM, 버전GET /system_stats
실행·대기 수GET /queue
GPU 사용률·온도·전력nvidia-smi --query-gpu=utilization.gpu,temperature.gpu,power.draw
최근 작업 시간GET /history?max_items=5
단계 진행률보조 스크립트가 읽는 웹소켓 /ws의 progress, executing와 comfy-cli 로그의 진행 막대

연속 3번 응답이 없으면 ComfyUI를 OFF로 표시하고, 그 뒤로는 10초마다 확인합니다. ComfyUI가 꺼져 있어도 /comfy-monitor on은 정상으로 실행됩니다. /system_stats에는 GPU 사용률이 없어서 nvidia-smi를 함께 씁니다.

NOTES만들면서 배운 것

  • 검증$를 받는 도우미 함수는 파일 최상위 function 선언이어야 validate를 통과합니다.
  • 터미널터미널 화면에도 SVG 키가 보이지만 아무것도 그리지 않아서, 화면 종류로 나눠 스파크라인을 씁니다.
  • 타이머모듈을 다시 불러오면 진행 중이던 조회가 거부되므로, 타이머 콜백의 Promise는 꼭 catch로 막습니다.
  • 웹소켓모드 안에서는 웹소켓을 쓸 수 없어 2초 조회로 하고, 단계 진행률은 보조 스크립트로 풀었습니다. ComfyUI는 작업을 넣은 클라이언트에게만 진행률을 보내므로, 다른 클라이언트 id로 붙지 않고 자기 id로 붙어 로그의 진행 막대를 함께 읽습니다.
