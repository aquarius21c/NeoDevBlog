comfy-monitor

ComfyUI 창을 띄우지 않고 돌릴 때, Claude Code 안에서 큐·VRAM·RAM·GPU 사용량을 상태줄과 그래프 패널로 보여 주는 모드(플러그인)입니다.

v0.3.0 테스트 12개 통과 plugin validate 통과 1단계(MVP) 완료 2026-10-12

WHY왜 만들었나요

Claude Code가 ComfyUI를 헤드리스로 실행해 영상을 만들게 하면, 지금 GPU가 얼마나 바쁜지, 큐에 작업이 몇 개 남았는지 볼 화면이 없습니다. 조사해 보니 ComfyUI 창 안에서 보는 도구(Crystools, Elegant Resource Monitor)는 있지만, Claude Code 안에서 ComfyUI 사용량을 그래프로 보여 주는 플러그인은 없었습니다. 그래서 직접 만들었습니다.

정리하면

ComfyUI 창을 띄워 두고 작업할 때는 Crystools로 충분하고, 창 없이(헤드리스로) 돌릴 때 이 모드가 필요합니다.

FEATURES기능

상태줄 한 줄 요약

실행·대기 수, VRAM, GPU 사용률을 늘 보이게 띄웁니다. ComfyUI가 응답하지 않으면 "꺼짐"으로 바뀝니다.

10분 그래프 패널

GPU·VRAM·RAM·큐를 최근 10분(샘플 300개) 그래프로 보여 줍니다.

안전한 종료

stop은 Claude가 띄운 ComfyUI만 끄고, 남은 작업이 있으면 먼저 물어봅니다.

INSTALL설치

명령을 입력하는 곳이 두 군데입니다

claude plugin … 명령은 PowerShell에, /reload-plugins와 /comfy-monitor … 같은 슬래시 명령은 Claude Code 입력창에 입력합니다.

상시 설치 (권장)

  1. 플러그인 폴더를 확인합니다. 숨김 폴더 .claude-plugin까지 함께 있어야 합니다. 
    claude plugin validate <플러그인 폴더>
  2. 폴더를 로컬 마켓플레이스로 등록하고 설치합니다. 
    claude plugin marketplace add <플러그인 폴더>
claude plugin install comfy-monitor@hg-local --scope user
claude plugin list
  3. plugin list에 enabled로 보이면 설치가 끝난 것입니다. 이미 열린 Claude Code에서는 /reload-plugins를 실행합니다. 설치 중 "userConfig 옵션 5개가 설정되지 않았다"는 안내가 나오는 건 정상이에요. 기본값을 씁니다.

설치 없이 한 번만 테스트

claude --plugin-dir <플러그인 폴더>

다른 PC로 옮길 때

폴더 전체를 복사한 뒤 위 순서대로 설치합니다. comfyBin 기본값은 만든 PC 기준 경로이므로, 받는 PC에서는 자기 comfy-cli 경로로 바꿔 주세요. 이 값은 /comfy-monitor stop에만 쓰입니다.

USAGE명령어

명령동작
/comfy-monitor그래프 패널을 엽니다. 모니터가 꺼져 있었으면 다시 켭니다.
/comfy-monitor on모니터를 켜고 패널을 엽니다.
/comfy-monitor off모니터만 끕니다. 조회를 멈추고 상태줄을 지웁니다.
/comfy-monitor stopComfyUI 자체를 종료합니다(comfy stop). 남은 작업이 있으면 먼저 묻습니다.
/comfy-monitor stop now남은 작업이 있어도 바로 종료합니다.
/reload-plugins모드 파일을 고친 뒤 재시작 없이 다시 불러옵니다.
off와 stop은 다릅니다

off는 모니터만 끄고 ComfyUI는 계속 돕니다. stop은 ComfyUI를 끄므로 진행 중인 생성도 멈춥니다. stop은 Claude(comfy-cli)가 백그라운드로 띄운 ComfyUI만 끄고, ComfyUI Desktop 앱은 끄지 않습니다. ComfyUI를 켜는 명령은 모드에 없으니 Claude에게 "ComfyUI 켜 줘"라고 하거나 comfy launch --background를 실행합니다.

CONFIG설정

Claude Code /config 또는 설정 파일의 pluginConfigs.comfy-monitor에서 바꿉니다.

키기본값의미

intervalSeconds2조회 주기(초)
useNvidiaSmitrueGPU 사용률·온도·전력을 nvidia-smi로 읽기
autoStarttrue끄면 세션 시작 때 조회하지 않고 on을 기다림
comfyBin<comfy-cli 경로>stop이 실행할 comfy-cli

HOW동작 방식

세션 시작→2초 타이머→/system_stats · /queue · nvidia-smi→링버퍼 300개(10분)→상태줄 · 패널
항목읽는 곳
VRAM, RAM, 버전GET /system_stats
실행·대기 수GET /queue
GPU 사용률·온도·전력nvidia-smi --query-gpu=utilization.gpu,temperature.gpu,power.draw
최근 작업 시간 (2단계)GET /history?max_items=5
단계 진행률 (2단계)웹소켓 /ws의 progress, executing

연속 3번 응답이 없으면 ComfyUI를 "꺼짐"으로 표시하고, 그 뒤로는 10초마다 확인합니다. ComfyUI가 꺼져 있어도 /comfy-monitor on은 정상으로 실행됩니다. /system_stats에는 GPU 사용률이 없어서 nvidia-smi를 함께 씁니다.

NOTES만들면서 배운 것

  • 검증$를 받는 도우미 함수는 파일 최상위 function 선언이어야 validate를 통과합니다.
  • 터미널터미널 화면에도 SVG 키가 보이지만 아무것도 그리지 않아서, 화면 종류로 나눠 스파크라인을 씁니다.
  • 타이머모듈을 다시 불러오면 진행 중이던 조회가 거부되므로, 타이머 콜백의 Promise는 꼭 catch로 막습니다.
  • 웹소켓모드 안에서는 웹소켓을 쓸 수 없어 1단계는 2초 조회로 하고, 실시간 진행률은 2단계 보조 스크립트로 풉니다.
